# Customer Intelligence Dashboard

A Machine Learning and Flask based web application that analyzes customer data, segments customers into different groups, and provides business insights through an interactive dashboard.

---

## Features

- Customer Data Analysis
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Segmentation
- Machine Learning Prediction
- Interactive Dashboard
- Business Insights
- Responsive User Interface

## Installation

Clone the repository

```bash
git clone https://github.com/Adityakarkare2006/Chrun-Vision-.git
```

Move to project folder

```bash
cd Chrun-Vision-
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment

Windows

```bash
venv\Scripts\activate
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Application

```bash
python app.py
```
